# OpenEdge ABL Toolkit — Comunidade

Portal público para suporte, relatos de problemas, sugestões e pedidos de
funcionalidades do **OpenEdge ABL Toolkit**.

## O que publicar aqui

- Relatos de bugs com passos reproduzíveis e dados sanitizados.
- Sugestões de melhorias.
- Pedidos de novas funcionalidades.
- Dúvidas gerais de uso que não contenham informações confidenciais.

Use os formulários em **Issues** ou inicie uma conversa em **Discussions**.

## Privacidade

Este repositório não contém o código-fonte, pacotes VSIX, instaladores,
configurações de bancos ou artefatos internos do produto.

Não publique:

- endereços IP, hostnames internos, portas ou topologia de rede;
- usuários, senhas, tokens, chaves ou arquivos de configuração;
- código-fonte proprietário;
- schemas, nomes sensíveis de bancos, tabelas ou campos;
- logs completos sem anonimização;
- vulnerabilidades de segurança.

Para uma vulnerabilidade, siga [SECURITY.md](SECURITY.md). O acesso ao produto
e aos instaladores é concedido separadamente pelo mantenedor a usuários
autorizados.

OpenEdge e Progress são marcas de seus respectivos proprietários. Este projeto
é independente e não é afiliado, patrocinado ou endossado pela Progress
Software Corporation.
