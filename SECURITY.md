# Segurança

Não abra uma issue pública para vulnerabilidades ou dados sensíveis.

Relate o problema de forma privada ao mantenedor do projeto pelo perfil
[Psykhepathos](https://github.com/Psykhepathos). Inclua somente as informações
necessárias e remova credenciais, dados empresariais e configurações reais.

O mantenedor confirmará o canal privado adequado antes de solicitar anexos ou
detalhes adicionais.
