# Segurança

Não abra uma issue pública para vulnerabilidades ou dados sensíveis.

Use o formulário de
[relato privado de vulnerabilidade](https://github.com/Psykhepathos/OpenEdge-ABL-Toolkit-Community/security/advisories/new).
Inclua somente as informações necessárias e remova credenciais, dados
empresariais e configurações reais.

O mantenedor confirmará o canal privado adequado antes de solicitar anexos ou
detalhes adicionais.
